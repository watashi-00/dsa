# DSA (Data Structures & Algorithms) Project

## Overview

A development environment and reference implementation for studying Data Structures and Algorithms.

## Structure

### dsa_java
Java-based implementations demonstrating data structures and algorithms with reflection capabilities.

Key components:
- `ClassScanner` - Discovers and loads classes from classpath locations
- `Inspector` interface - Abstracts inspection logic for challenge metadata
- `Challenge` annotation - Marks classes as challenges with platform, difficulty, and topics
- `ListNode` - Node class for linked list data structure
